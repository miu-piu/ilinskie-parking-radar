# Радар паркинга «Ильинские луга»

Локальный радар для первого аукциона машиномест ПИК в паркинге 31.1 ЖК «Ильинские луга» 3 ноября 2026 года.

## Что уже работает

- в `data/seed_lots.csv` загружены **все 70 лотов** первого аукциона из прайса ПИК;
- каждый лот опрашивается напрямую через `https://api.pik.ru/v2/flat?id=<артикул>`;
- API отдаёт номер места, уровень, площадь, текущую цену, статус, число ставок (`auctionBidsCount`) и даты аукциона;
- один тестовый прогон успешно получил **70 из 70** карточек;
- история каждого снимка сохраняется локально в SQLite;
- интерфейс считает не только текущую цену, но и **цену входа**: если ставок уже есть хотя бы одна, для входа нужна текущая цена + шаг 20 000 ₽;
- жёсткий потолок покупки — **1 650 000 ₽**;
- автоматических ставок нет и не будет: решение и ставка остаются ручными.

Контрольная карточка:

- №170: https://www.pik.ru/parking/1070586

## Как устроен мониторинг

`collector.py` берёт артикулы из `data/seed_lots.csv` и параллельно запрашивает все карточки через API ПИК. Сейчас это надёжнее общего каталога: аукционные машиноместа 31.1 не появляются в обычной выдаче `v2/filter`, зато прямые карточки доступны.

По умолчанию используется 6 параллельных запросов. Интервал полного автоопроса в интерфейсе — 30 секунд; его можно уменьшить в день торгов, но слишком частый опрос 70 карточек без необходимости лучше не использовать.

SQLite-файл создаётся локально как `data/parking.sqlite` и не коммитится в GitHub.

## Подтверждённая механика аукциона

- плата за участие — 20 000 ₽ отдельно за каждый лот;
- плата вносится один раз за лот, а не при каждом повышении;
- шаг цены машиноместа — 20 000 ₽;
- к новому лоту можно присоединиться в любой момент до окончания его торгов;
- история ставок видна по всем объектам;
- ставка в последние 10 минут продлевает торги на 10 минут;
- абсолютный потолок покупки — **1 650 000 ₽**.

## Премиальные лоты

## GitHub и live-режим

GitHub хранит код, настройки и модель. GitHub Actions проверяет код и доступность API. Для обновления каждые 10–30 секунд в сам день аукциона лучше запускать Streamlit локально: GitHub Actions не предназначен для непрерывного опроса с такой частотой.

## Слой оценки по другим ЖК

Отдельно строится база аналогов ПИК **2025–2026**. Старые аукционы можно хранить как фон, но не давать им существенный вес.

Основные нормализованные показатели:

1. цена машиноместа / цена 1 м² квартиры в том же ЖК на ту же дату;
2. цена 1 м² машиноместа / цена 1 м² квартиры;
3. цена 1 м² машиноместа / цена 1 м² кладовой;
4. тип паркинга: наземный многоуровневый или подземный;
5. стадия строительства и заселённости;
6. доля проданных квартир;
7. обеспеченность парковкой;
8. автозависимость ЖК и качество общественного транспорта;
9. первый или последующий выпуск машиномест;
10. фактический рост на аукционе и цена следующего выпуска.

Для «Ильинских лугов» транспортная похожесть особенно важна: проекты у метро нельзя считать равными аналогами без поправки.
