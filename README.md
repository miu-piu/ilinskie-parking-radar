# Этикетки — Android
Тестовая версия для организации домашних вещей и печати на AIYIN IP-802BT.

Каталог, поиск, редактор, очередь по три этикетки на листе 75 × 120 мм. Bluetooth Classic SPP и тестовая печать TSPL. Совместимость с прошивкой принтера пока не подтверждена.

GitHub Actions собирает подписанный debug APK в Actions → Artifacts.

История прежнего парковочного проекта сохранена в Git.
