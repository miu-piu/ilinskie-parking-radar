# Радар паркинга «Ильинские луга»

Локальный радар для аукциона машиномест ПИК в паркинге 31.1 ЖК «Ильинские луга».

## Задача

Система должна помогать принять решение во время торгов, а не делать ставки вместо человека:

- собирать текущие цены и статусы машиномест;
- сохранять историю изменений в SQLite;
- сравнивать «премиум для себя» и «дешёвое приемлемое»;
- считать цену комфорта — доплату за широкое место и близость к лифту;
- соблюдать абсолютный потолок покупки **1 650 000 ₽**;
- позже учитывать аналоги аукционов ПИК 2025–2026, цены квартир, кладовых и автозависимость ЖК.

Контрольная карточка ПИК:

- №170: https://www.pik.ru/parking/1070586

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python collector.py
streamlit run app.py
```

## Как работает сборщик

`collector.py`:

1. пробует получить контрольный объект `1070586` через JSON API ПИК;
2. пытается автоматически определить `block_id`;
3. запрашивает объекты типа `5` (паркинг);
4. сохраняет сырые ответы в `data/raw/` для диагностики;
5. записывает найденные цены и статусы в `data/parking.sqlite`.

Если автоматическое определение не сработало, `block_id` можно передать вручную:

```bash
PIK_BLOCK_ID=1234 python collector.py
```

До подтверждения API интерфейс всё равно работает на известных нам лотах из `data/seed_lots.csv`.

## Стратегия аукциона

Правила, которые уже подтверждены поддержкой ПИК:

- плата за участие — 20 000 ₽ отдельно за каждый лот;
- шаг цены машиноместа — 20 000 ₽;
- к новому лоту можно присоединиться до окончания аукциона;
- история ставок видна по всем объектам;
- ставка в последние 10 минут продлевает торги на 10 минут;
- абсолютный потолок покупки — **1 650 000 ₽**.

### Премиальные лоты

- №170 — уровень 3, 15,4 м², старт 1 555 000 ₽, артикул 1070586;
- №233 — уровень 4, 15,4 м², старт 1 509 000 ₽, артикул 1070647;
- №296 — уровень 5, 15,4 м², старт 1 478 000 ₽, артикул 1070712.

### Основная идея выбора

У нас два осмысленных сценария:

1. **Премиум для себя** — широкое место около лифта, если доплата к дешёвой альтернативе разумна.
2. **Дешёвое приемлемое** — минимальный вложенный капитал, если премиальные места разогнали.

«Средний» вариант без явного преимущества специально не считается целью.
